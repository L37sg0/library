## Virtual Machines
- Virtual machines run operating systems in a protected space
- VMs share host resources
- Often used for labs and for testing software
- Can be used to run software which doesn't run on the host OS
- KVM(Kernel Virtual Machine) and QEMU are commonly used to host VMs on Linux hypervisors

## Installation and usage
- `sudo apt install qemu-kvm` - install the software
- `qemu-img create -f qcow2 ubuntudesktop.qcow2 80G` - create a file that will serve as a disk image for our VM
```bash
sudo qemu-system-x86_64 -cpu host -enable-kvm -m 16G -smp 4 -drive file=ubuntudesktop.qcow2 \
-vnc :1 -device nec-usb-xhci,id=usb,bus=pci.0,addr=0x4 \
-device usb-tablet -cdrom ubuntu-21.04-desktop-amd64.iso
```
  - `-cpu` - exposes the host cpu to the VM, and enables virtualization on itself, and also tells the VM to work only with this cpu, so it could not be moved to another host
  - `-enable-kvm` - tells QEMU to use the KVM kernel functionality, to use real virtualization, rather than to emulate the whole system
  - `-m 16G` - tells QEMU how much memory to use for the VM
  - `-smp 4` - provide 4 processor cores to the VM
  - `-drive file=ubuntudesktop.qcow2` - tells QEMU which file to use as the system disk.
  - `-vnc :1` - provides a guest system level VNC display on a port on host IP address, where we to connect to, where we can interact with the guest OS, just like we have display, mouse and keyboard attached.
    - pointing 1 here means port 5901
    - we need to open this port in the firewall - `sudo ufw allow 5901`
  - `-device nec-usb-xhci,id=usb,bus=pci.0,addr=0x4` - adds a usb bus to the VM
  - `-device usb-tablet` - fixes issues with moude pointer, so we need this
  - `-cdrom ubuntu-21.04-desktop-amd64.iso` - tells QEMU what file to use as installation media for this VM.

- We can interact with the VM with `remmina`, by selecting `VNC` type of connection, and pointing to host IP address and port, `10.10.2.100:5901`
- To run the VM again we could do it by using the command we created the VM with, by ommiting the `-cdrom` directive.
- Then install an `SSH` server on the VM - `sudo apt install openssh-server`
- Then allow port 2222 on the host - `sudo ufw allow 2222`
- Then add a network device to the VM and forward 2222 host port to 22 guest port
  - `-device e1000,netdev=ne0 -netdev user,id=net0,hostfwd=tcp::2222-:22`
- Then connect from host to guest via SSH - `ssh -oPort=2222 user@10.0.1.100`

- **It is good practice to use the VM initialization scripts in file, so to be sure we're running same VM**
- **Also it is good practice to start VM using tmux, because interupting the command for initialization will terminate the VM**
- **A graphical management software like `Buxus` or `virt-manager` (or any other clients supporting `libvirt`) can also be used to manage VMs**
- [more info on libvirt](https://libvirt.org/index.html)
