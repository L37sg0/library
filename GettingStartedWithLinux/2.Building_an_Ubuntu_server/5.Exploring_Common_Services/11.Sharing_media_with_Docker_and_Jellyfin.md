## Media Streaming Services
- Many services offer media streaming
- [Plex](https://www.plex.tv/) and [Jellyfin](https://jellyfin.org/) are commonly used
- Jellyfin is open source and has clients available for many platforms
- Jellyfin can be compiled from source, installed as a package, or run in a Docker container

## Jellyfin setup
- prepare some media files
- `mkdir /mnt/storage/media` - prepare media folder
- move media files in the media folder using `cp` or `mv`
- files need to bea readable from all users, so fix permissions using `chmod +r /mnt/storage/media`
- [Jellyfin server installation instructions for docker](https://jellyfin.org/downloads/docker)
  - ```bash
    docker pull jellyfin/jellyfin:latest  # or docker pull ghcr.io/jellyfin/jellyfin:latest
    mkdir -p /srv/jellyfin/{config,cache}
    docker run -d -v /srv/jellyfin/config:/config -v /srv/jellyfin/cache:/cache -v /mnt/storage/media:/media --net=host jellyfin/jellyfin:latest
    ```
    - in last command option `-d` will run container in background, rather than ocupy the shell session
    - option `-v` specifies volume to binf mount from host to guest
    - option `--net=host` means server will run on host IP address
  - `sudo docker container ls` to verify Jellyfin is running
- open port on firewall to allow Jellyfin access
  - `sudo ufw allow 8096/tcp` - the port Jellyfin uses for HTTP, will be used durring configuration
  - `sudo ufw allow 8920` - for HTTPS
- [Jellyfin documentation](https://jellyfin.org/docs/)

## Running a Jellyfin Server
- **Ensure the Docker container runs automatically.**
  - Append `--restart=always` to the `docker run` command.
  - Or create a systemd unit file to control the container like a service.
- **Improve security and create non-priviledged users.**
  - Add HTTPS support to secure the service.
  - Create user accounts for people using your service.
