## Challenge: Parse information from a text file
- Extract `log.tar.gz` from the [Excersize files](https://github.com/L37sg0/learning-linux-command-line-3005201/tree/main/Exercise%20Files)
  - `tar -xvf log.tar.gz` - new file called `auth.log` would appear
  - 
- Look for unauthorized connection attempts
  - `grep 'input_userauth_request' auth.log | sort -u`
- Extract the usernames an attacker tried to use and 
  - Create a file containing these names and make it organized
  ```bash
  $ cat auth.log | grep 'input_userauth_request' | awk '{print $9}' | sort -u 1> users.txt
  $ tail -f users.txt 
  welcome
  www
  www1
  xbmc
  xbox
  zabbix
  zarafa
  zxin10
  zxin20
  zznode
  ^C
  $ 
  ```
    - `grep 'authentication failure' auth.log | sort -u | awk '{print $15}' | sort -u 1> attackers.log`
