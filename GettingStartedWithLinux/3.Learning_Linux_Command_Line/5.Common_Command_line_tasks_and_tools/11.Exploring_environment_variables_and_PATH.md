## Environment variables
- use `env` to explore system environment variables
- use `echo $PATH` to explore speciffically the `PATH` variable

## Editing $PATH Variable
- We can modify where the system looks for executables
- This allows use to use programs stored in nonstandard locations more easily
- Edit the shell profile file (~/.bash_profile)
- File names begginning with a period are typically hidden from view

- create a new file `nano ~/.bash_profile`
- add aditional directories to your PATH with
  ```bash
  #GNU nano 4.8                                            /home/codespace/.bash_profile                                            Modified  
  PATH="$PATH:my/custom/path:/some/other/path:/etc/other/path"
  ```
