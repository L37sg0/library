## Tools for working with Text
- `awk`
  - Often used to extract specific text from a file according to a rule
  - `awk` programs can be writen at the command line or stored in a file
  - more info [AWK Essentials Training](https://www.linkedin.com/learning/awk-essential-training/welcome-17099300)
    
- `sed`
  - Is a stream editor
  - Often used for modifying text in a command pipeline or in place

- `rev`
  - Prints text in reverse sequence
- `tac`
  - Concatenates or displays files in reverse - reverse `cat`
- `tr`
  - Translates or modifies individual characters according to parameters


## Examples
- use `awk` to print columns of data and sort to sort the text by ID for example:
  ```bash
  $ cat simple_data.txt                                # See original content of file
  Name    ID      Team
  Scott   314     Purple
  Ananti  991     Orange
  Jian    3127    Purple
  Miguel  671     Green
  Wes     1337    Orange
  Anne    556     Green
  $ awk '{print $2 "\t" $1}' simple_data.txt           # Print ID and Name columns only
  ID      Name
  314     Scott
  991     Ananti
  3127    Jian
  671     Miguel
  1337    Wes
  556     Anne
  $ awk '{print $2 "\t" $1}' simple_data.txt | sort -n  # Sort the content by the ID column
  ID      Name
  314     Scott
  556     Anne
  671     Miguel
  991     Ananti
  1337    Wes
  3127    Jian
  ```
  - use `sed` to change Orange to Red in the text file
  ```bash
  $ cat simple_data.txt               # Print original data
  Name    ID      Team
  Scott   314     Purple
  Ananti  991     Orange
  Jian    3127    Purple
  Miguel  671     Green
  Wes     1337    Orange
  Anne    556     Green
  $ sed s/Orange/Red/ simple_data.txt  # Change Orange with Red
  Name    ID      Team
  Scott   314     Purple
  Ananti  991     Red
  Jian    3127    Purple
  Miguel  671     Green
  Wes     1337    Red
  Anne    556     Green
  ```
  - use `sort` to sort data by the second column "ID"
  ```bash
  $ cat simple_data.txt      # Print original data
  Name    ID      Team
  Scott   314     Purple
  Ananti  991     Orange
  Jian    3127    Purple
  Miguel  671     Green
  Wes     1337    Orange
  Anne    556     Green
  $ sort simple_data.txt      # By default it sorts data alphabetically by the first column
  Ananti  991     Orange
  Anne    556     Green
  Jian    3127    Purple
  Miguel  671     Green
  Name    ID      Team
  Scott   314     Purple
  Wes     1337    Orange
  $ sort -k2 simple_data.txt    # With `-k2` we tell it to use the secont column for sorting
  Wes     1337    Orange
  Scott   314     Purple
  Anne    556     Green
  Name    ID      Team
  Jian    3127    Purple
  Miguel  671     Green
  Ananti  991     Orange
  $ sort -k2 -n simple_data.txt  # With `-n` we tell it to sort it numerically
  Name    ID      Team
  Scott   314     Purple
  Anne    556     Green
  Miguel  671     Green
  Ananti  991     Orange
  Wes     1337    Orange
  Jian    3127    Purple
  ```
  - show only unique lines from text file with `sort`
  ```bash
  $ cat dupes.txt                  # Print original file
  Here's a line of text.
  Here's a line of text.
  Text can be easy to work with.
  But some text can be tricky.
  Here's a line of text.
  Text can be easy to work with.
  $ sort -u dupes.txt              # Show only unique lines
  But some text can be tricky.
  Here's a line of text.
  Text can be easy to work with.
  ```
