## Redirection
- Text in a shell travels through one of three streams
- Text can be redirected to the screen or to files

|Stream|Number|Usage|
|-|-|-|
|Standard Input(stdin)|0|Text input|
|Standard Output(stdout)|1|Text output|
|Standard Error(stderr)|2|Error text|

## Examples
- Redirecting Standart Output `1`
  ```bash
  $ ls 1> filelist.txt  # Here we tell shell to redirect the standart output to a text file
  $ cat filelist.txt 
  departments
  dupes.txt
  filelist.txt
  log.tar.gz
  poems.txt
  simple_data.txt
  test.sh
  $ ls > filelist2.txt # Here we tell the shell same as above, but without specifying redirect type
  $ cat filelist2.txt 
  departments
  dupes.txt
  filelist.txt
  filelist2.txt
  log.tar.gz
  poems.txt
  simple_data.txt
  test.sh
  ```
- Redirecting Error Output `2`
  ```bash
  $ ls notreal                                            # This would return an error because we try to access something which doesn't exist
  ls: cannot access 'notreal': No such file or directory
  $ ls notreal > filelist3.txt                            # This would also return the error above, because we're not specifying the redirection type
  ls: cannot access 'notreal': No such file or directory
  $ ls notreal 2> filelist4.txt                           # Finally when we specify redirection to be  2 - errors, error is no longer returned in terminal, but writen in the file instead
  $ cat filelist4.txt 
  ls: cannot access 'notreal': No such file or directory
  ```
- Emptying an Appending content to a file, using redirections
  ```bash
  $ cat filelist4.txt                                     # Our file has som content
  ls: cannot access 'notreal': No such file or directory
  $ >filelist4.txt                                        # Redirecting an empty string to a file, leads to file being empty
  $ cat filelist4.txt 
  $ ls > filelist5.txt                                    # Redirect content to a new file
  $ echo "some appended text" >> filelist5.txt            # Use double >> to append output to a file
  $ cat filelist5.txt
  departments
  dupes.txt
  filelist.txt
  filelist2.txt
  filelist3.txt
  filelist4.txt
  filelist5.txt
  log.tar.gz
  poems.txt
  simple_data.txt
  test.sh
  some appended text                                      # This is our appended text
  ```
