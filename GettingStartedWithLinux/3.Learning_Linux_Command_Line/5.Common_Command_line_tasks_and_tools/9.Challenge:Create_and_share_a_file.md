## Challenge: Create and share a file
- Create a text file
  - `touch new-file.txt`
  - can also be done using `nano` or `vim`
- Ensure any user can read and write it
  - to check current file permissions use `stat new-file.txt`
  - `chmod 666 new-file.txt` or `chmod a+rw new-file.txt`
- Compress the file using `tar` or `zip`
  - `tar -caf new-file.tar.gz new-file.txt` or `tar -czf new-file.tgz new-file.txt`
