## Pipes
- Pipes take the output of one command and send it to another.
- `cat users.txt | sort -u | ...` - takes output of the `cat` command and passes the output to `sort` command
- the pipe character is `|`
- Examples
  - `echo "Hello" | wc` - `1 1 6` - one  line, one word, 6 characters
