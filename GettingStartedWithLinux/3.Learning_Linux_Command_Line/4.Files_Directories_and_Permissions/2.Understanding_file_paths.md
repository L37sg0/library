## Paths on Linux
- A path represents the location of a file or directory
- Paths use the slash character `/` as a separator between directory or file names
- Paths can be absolute or relative

## Absolute Paths
- Begins from the root of the file system
- Defines an explicit location on the file system
```bash
/home/username/     # Absolute path to user home directory
/home/username/Documents # Absolute path to user Documents folder in his home directory
# A slash at the begining indicates an absolute path
```
|Working Directory|Relative Path|Resulting Absolute Path|
|-|-|-|
|`/home/user`|Documents|`/home/user/Documents`|
|`/home/otheruser`|Documents|`/home/otheruser/Documents`|
|`/home/user/Pictures`|Documents|~~`/home/user/Pictures/Documents`~~|


**Having no slash at the begining indicates a relative path.**

## Relative Paths
- The name `..` refers to the parent directory of the current working directory

|Working directory|Relative Path|Resulting Absolute Path|
|-|-|-|
|`/home/user`|`..`|`/home`|
|`/home/user/Documents`|`..`|`/home/user`|
|`/home/user/Pictures`|`../Documents`|`/home/user/Documents`|

## Tilde Expansion
- The `~` tilde character refers to the current user's home directory
- My documents (and your documents) are at the path `~/Documents`
- The shell expands the character `~` to the path of the user's home directory.

`~/Documents` `->` `/home/user/Documents`

`~/Documents` `->` `/home/anotheruser/Documents`

**Both absolute and relative paths are useful.**

**Absolute paths start with a slash `/` , relative paths do not.**
