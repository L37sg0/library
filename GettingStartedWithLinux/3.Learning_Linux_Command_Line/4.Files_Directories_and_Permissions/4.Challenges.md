## Fix a broken syntax
- Correct the commands bellow and describe the errors in each
  - `cd ~/home/scott` - right will be `cd ~` - error will be `Directory /home/scott/home/scott does not exist`
  - `LS /home` - right will be `ls /home` - error will be `LS command not found`
  - `mv ~/log.tar.gz home scott` - right will be `mv ~/log.tar.gz /home/scott` - error wil be `Directory scott is not defined`
  - `chmod ~/log.tar.gz` - need to pass permission mode - example `chmod +x ~/log.tar.gz`
