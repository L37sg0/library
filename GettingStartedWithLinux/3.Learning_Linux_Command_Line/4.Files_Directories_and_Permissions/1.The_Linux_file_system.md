## Commands for file Information
- `file` - determine file type
- `stat` - display file status

## How Directories are organised
- We need to know where files and commands can be found
- The file system keeps track of and represents files on the system's storage
- Filesystem Hierarchy Standart (FHS) defines common locations for files across many Linux distributions.

## Notable File System Directories
- File system root `/`
    - contains all other directories
    - Highest level of the file system hierarchy
- User home directories: `/home`
- Root user's home directory: `/root`
- Common configuration files: `/etc`
- Common programs or commands: `/bin, /sbin`
- Shared libraries and modules: `/lib`
- Standart location for mounting other file systems: `/mnt, /media`
- Kernel and system information: `/dev, /proc, /sys`

## Home Directories
- Location where each user's personal files are stored
- Each user has their own directory within `/home/<username>`
- In Bash and many other shells, each user's own home directort is represented by the tilde (~) character
- On desktop distros, the home directory often contains subdirectories like Documents, Downloads, and Pictures
