## Navigating file system
- use `cd` command to move between direcotries
    - `cd ~/Documents` - goes to `/home/user/Documents`
    - `cd ..` - goes to parent directory of the current directory
    - `cd -` - use it to swith between 2 directories
    - `cd` - will take you to your home directory
- use `ls` to explore files and folders
    - `ls -R` - to explore files and directories recursively
- use `pwd` - to show absolute path of current working directory

## Create and remove directores
- use `mkdir` to create new directories
    - `mkdir -p` will create parent directories as well
    - `mkdir ~/Documents/folder1`
- use `rmdir` to remove directories - need to be empty
- Both can be used for create/remove multiple directories as well
    - `mkdir -p dir1/dir2 dir1/dir3 ...`
    - `rmdir dir1 dir2 dir3 ...`

## Create, edit, delete files
- use `touch filename` to create a file
- use `rm filename` to remove file
- use shell text editor like `nano` or `vim` to edit files 
    - `nano filename` - will open file in nano text editor

## Copy, move and delete files and directories
- use `cp source destination` to copy files
- use `mv source destination` to move files
- use `mv oldname newname` to rename files
- use wildcards to cp or mv multiple files and directories at once
    - `mv *.txt departments/marketing` - move all txt files from current workdir to the target directory
    - `rm poem?.txt` - to remove all (poem1.txt, poem3.txt)
    - `rm -r target` will remove target recursively, in case it is not empty directory.
