## Navigating file system
- use `cd` command to move between direcotries
    - `cd ~/Documents` - goes to `/home/user/Documents`
    - `cd ..` - goes to parent directory of the current directory
    - `cd -` - use it to swith between 2 directories
    - `cd` - will take you to your home directory
- use `ls` to explore files and folders
    - `ls -R` - to explore files and directories recursively
- use `pwd` - to show absolute path of current working directory

## Create and remove directores
- use `mkdir` to create new directories
    - `mkdir -p` will create parent directories as well
    - `mkdir ~/Documents/folder1`
- use `rmdir` to remove directories - need to be empty
- Both can be used for create/remove multiple directories as well
    - `mkdir -p dir1/dir2 dir1/dir3 ...`
    - `rmdir dir1 dir2 dir3 ...`

## Create, edit, delete files
- use `touch filename` to create a file
- use `rm filename` to remove file
- use shell text editor like `nano` or `vim` to edit files 
    - `nano filename` - will open file in nano text editor

## Copy, move and delete files and directories
- use `cp source destination` to copy files
- use `mv source destination` to move files
- use `mv oldname newname` to rename files
- use wildcards to cp or mv multiple files and directories at once
    - `mv *.txt departments/marketing` - move all txt files from current workdir to the target directory
    - `rm poem?.txt` - to remove all (poem1.txt, poem3.txt)
    - `rm -r target` will remove target recursively, in case it is not empty directory.
## Find files from command line
- `find . -name "po*"` - will find all files starting with `po` in current workdir

## Understand file permissions
### Octal permissions

| |Read(4)|Write(2)|Execute(1)|Result|
|-|-|-|-|-|
|User|r|w|x|7|
|Group|r|-|x|5|
|Others|r|-|-|4|

- `rwxr-xr--`
    
### Symbolic file permissions

| |read(r)|Write(w)|Execute(x)|Mode|
|-|-|-|-|-|
|User(u)|+|+|+|u+rwx|
|Group(g)|=| | |g=r|
|Others(o)|-| | |o-rwx|
|All(a)|=|=|=|a=rwx|

- `+` adds persmission
- `-` removes permission
- `=` resets permission to match new mode, removes previous mode

### Comparing Octal and Symbolic Values
|Octal Value|Symbolic Value|Result|
|-|-|-|
|`777`|`a=rwx`|`rwxrwxrwx`|
|`755`|`u=rwx,g=rx,o=rx`|`rwxr-xr-x`|
|`644`|`u=rw,g=r,o=r`|`rw-r--r--`|
|`700`|`u=rwx,g-rwx,o-rwx`|`rwx------`|

### Symbolic Value Changes Example
|Original Mode|Symbolic Value|Result|
|-|-|-|
|`rw-r--r--`|`+x`|`rwxr-xr-x`|
|`rwxrwxrwx`|`g=w,o=r`|`rwx-w-r--`|
|`rwxr-----`|`g+w,o+r`|`rwxrw-r--`|
|`rwxrwxrwx`|`a-x`|`rw-rw-rw-`|

## Modify file persissions and owners
- use `chmod` for changing permissions
- use `chown` for changing user and group owners of the files

## Create hard and symbolic links
### Links
- Links are files that reference other files
    - Used to avoid having duplicate files
    - A link establishes a pointer in one place to a destination in another place.
- Two types of links:
    - A hard link points to specific data (by inode) on the disk
    - A soft link or symbolic link (symlink) points to another file
- `ln -s source.txt linkname.txt` - create a soft (symlink)
  ```bash
    lrwxrwxrwx  1 reghack reghack       7 Apr  9 09:50  testlink.sh -> test.sh*
  ```
  - **Important notice here is this link is relative. If we move the source file or the link file, link will stop work.**
- `ln source.txt linkame.txt` - by ommiting the `-s` option we make a hard link, which can be moved without breaking the link.
