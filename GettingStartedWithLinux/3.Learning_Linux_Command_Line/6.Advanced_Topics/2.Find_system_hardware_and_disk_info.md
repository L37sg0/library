  ```bash
  $ free -h

  Mem:          7.7Gi       1.4Gi       142Mi       1.0Mi       6.2Gi       6.0Gi
  Swap:            0B          0B          0B
  ```

  /dev/loop3       32G   14G   16G  47% /workspaces
