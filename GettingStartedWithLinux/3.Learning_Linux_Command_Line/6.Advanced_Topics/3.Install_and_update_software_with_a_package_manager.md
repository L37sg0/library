## Package managers
- **Each distribution has its own package manager**
- Debian and similar distros (Ubuntu, Mint and so on) use `APT`
- Red Hat and CentOS use `YUM` or `DNF`, and Fedora uses `DNF`
- SUSE uses `YaST`
- Arch uses `pacman`
- They all allow us to search for, install, remove, and update packages.

- get updated list for package repository mirrors with `sudo apt update`
- install package called `tree` with `sudo apt install tree`
- upgrade system software with security patches and bugfixes with `sudo apt upgrade`
- **We need superuser `sudo` privileges to be able to update and install software**
- **When software is installed with the package manager, it will come with its manual `man` pages**
