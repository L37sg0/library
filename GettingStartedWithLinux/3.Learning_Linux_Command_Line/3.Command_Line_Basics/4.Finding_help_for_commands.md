## Manual pages
- You don't have tp memorize everything
- The commands `man` opens the manual pages
- Manual pages are the built-in documentation for commands.

## Other useful commads
- `<command> --help` - shows help for a command
- `help` - shows help for the shell and list of common commands
- `apropos <keyword>` - gives you list of available commands via keyword
