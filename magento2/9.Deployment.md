# Записки от Стойко
```bash
git clone project
git clone module 
```

## В проекта
```bash
	3. Провери бранчовете
	4. git pull
	5. composer install, set:up, set:di:compile
	6. Провери модула, който изнасяш дали е на последна версия
	7. Копираме файловете на модула от local-src и до composer.json включително в проекта 
```

## В модула който се изнася
```bash
	9. git pull в модула
	10. Поставяме всичко копирано от проекта в модула до composer.json и поставяне в модула
	11. променяме в changelog.md, (изтриваме rc). Там ни е водещо. 
	12. променяме в etc/module.xml версията (както е в changelog.md)
	13. променяме в composer.json, (изтриваме rc) (както е в changelog.md)
	14. git status
	15. git add . 
	16. git reset HEAD .idea/ - махаме конф. на phpstorm
	17. „v<версия на модула> - <какво е правено> #124676„ - номера на тикета за изнасяне
	18. git push
	19. git tag
	20. git tag 'v1.0.4'
	21. git push --tags
```

## Връщаме се в проекта "Да преинсталираме проекта с новата версия на модула"
```bash
	22. Изтриваме модула от local-src 
	23. Изтриваме от composer.json на repositories (ако го има там): { local-stenik-module.....}
	24. Взимаме от https://packages.stenikgroup.com/magento2/ - нашият модул
	25. Инсталираме го отново модула през composer require <module name> <new version>
	26. добавяме git add composer.json composer.lock
	27. git commit -m "" 
		 -> Update stenik/module-pcd-price to version 1.0.3 <номера на референтния тикет>  
	28. git push
	29. Деплойваме проекта
```

## В Redmine
```bash
	30. Отиваме в News, добавяме новина и пишем заглавие <име на модула> <версия> и описание какво е променено.
		Също добавяме и Ref: номера на тикета, който е насочен към нас за изнасяне.
		
	31. Отиваме в parent тикета на модула за смяна на версията 
	(ако е записано там или ако има такъв тикет) - горе в ляво 
		-вдигаме версията на модула
	
	32. Вписваме инфо в референтният тикет, че е преинсталиран модула
	Модулът *stenik/module-smile-elasticsuite-brands* е актуализиран до версия @1.0.1@

	33. Отиваме на тикета, който е насочен към нас и 
	променяме заглавието на „v<версия на модула> - <какво е правено>„
	
	34. Връщаме тикета и пишем коментар "Корекциите са изнесени в composer" и done: 100%
```
