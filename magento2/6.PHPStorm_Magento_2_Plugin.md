## Description
- A plugin which recognises magento-design-patterns, and also has maker - simmilar to Symfony maker, but in the UI,
- source: https://plugins.jetbrains.com/plugin/8024-magento-phpstorm
- for issues: https://www.astralwebinc.com/magento-phpstorm-plugin-not-working/

## Personal Notes
- need to be enabled per project in `File/Settings/PHP/Frameworks/Magento`
- **will not generate license files, just mentions used licenze in composer.json**
- **will not generate README.md file based on description, instead will add it in composer.json under `description` - so text should be short!**

## Create new module
- right click on `app/code/<VENDOR-NAME>`
- select `New/Magento 2 Module`

## Create db_schema.xml and db_schema_whitelist.json
- right click on your module root folder `etc`
- select `New/Module File/Magento 2 Declarative Schema XML`

## Create new controller
- right click on module root folder
- select `New/Module File/Magento 2 Controller`
- example to create admin controller `Controllers/Profile/Edit.php` - which should return edit form
    - `Target Area` - `adminhtml`
    - `HTTP Method` - `GET`
    - `Action Name` - `Edit`
    - `Action Path` - `Profile`
    - click `OK`

## Create new router
- example for creation of admin router
    - create folder `adminhtml` under your module root folder `etc` - aka `app/code/Vendor/Module/etc/adminhtml`
    - right click and select `New/Magento 2 Routes File`
    - fill `ROUTE_ID` - lowercase `something_related_with_your_module`
    - fill `FRONT_NAME` - lowercase `something-related-with-your-module`
    - click `OK`

## Create domain layer (Models)
- right click module root and select `New/Module File/Magento 2 Models`
- fill fields
- click `OK`
- will generate a Model, ResourceModel and Collection classes under `app/code/Vendor/Module/Model`
