## Slack
- **Put a picture in your profile**
- **Write your position**
- Channels
    - `#general` - for events and important things only
    - `#work-time-changes` - when you'll be late, when you'll not be available for something, when you'll go for a break etc.
    - `#development` - a channel for all developers, being used mostly on Fridays, or to find support from collegues when stuck on something.
    - `#dev-commits` - channel for automated commit notifications from gitlab
    - `#deployment` - channel for automated deploy messages from gitlab
    - `#random` - for non-work-related stuffs
- Workflow
    - channels for each project - `#proj_<PROJECT_NAME>`
    - use threads to repply collegue messages in channels
    - use tags `@CollegueName`, `@here` etc. to reach somebody

## Redmine
- a project-management system
- receiving tasks
- logging time per tasks
- Workflow
    - click on `My Page` - to see assigned tasks for you
    - click on `Projects` - to see available for you projects
    - go to `Issues`
    - if have questions go in Slack and ask in the project channel
