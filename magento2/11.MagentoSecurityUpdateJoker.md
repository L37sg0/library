## If missing Zend classes on `compile`
```bash
m2 composer require typo3/class-alias-loader
```

- Add this to your composer.json in the `extra` sectin or [Use the documentation](https://github.com/TYPO3/class-alias-loader)
```json
,
        "typo3/class-alias-loader": {
            "class-alias-maps": [
                "laminas-zend-map.php"
            ]
        }
```
- Identify missing classes via:
```bash
grep -rnw -ie "Zend" app/code
```

- Add this file to your project root folder and if needed add or remove aliases
```php
<?php // laminas-zend-map.php
return [
    'Zend_Json' => Laminas\Json\Json::class,
    'Zend\\Json\\Json' => Laminas\Json\Json::class,
    'Zend_Validate_Interface' => Laminas\Validator\ValidatorInterface::class,
    'Zend\\Http\\Client\\Adapter\\Curl' => Laminas\Http\Client\Adapter\Curl::class,
    'Zend\\Http\\Response' => Laminas\Http\Response::class,
    'Zend\\Http\\AbstractMessage' => Laminas\Http\AbstractMessage::class,
    'Zend\\Uri\\Http' => Laminas\Uri\Http::class,
    'Zend\\Uri\\Uri' => Laminas\Uri\Uri::class,
    'Zend\\Uri\\UriFactory' => Laminas\Uri\UriFactory::class,
    'Zend\\Log\\Writer\\Stream' => Laminas\Log\Writer\Stream::class,
    'Zend\\Mime\\Message' => Laminas\Mime\Message::class,
    'Zend\\Mime\\Part' => Laminas\Mime\Part::class,
//    'Zend\\Serializer\\Serializer' => Laminas\Serializer\Serializer::class, requires laminas/laminas-serializer
];

```
- Then run again `setup:upgrade` `setup:di:compile` and check your storefront and admin. Make sure they work , make a test order and see it appears in admin
