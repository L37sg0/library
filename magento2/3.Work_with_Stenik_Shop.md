## Learn how to work with Stenik_Shop magento2 module

- [x] Add 2 physical stores in the listing
 - Log in admin panel and go to `Stenik/Shops/Add New Shop`
 - Fill `Shop Name`
 - Set `Is Active - Yes`
 - Set `Is Active On Front-End - Yes`
 - Fill `City`, `Address`, `Phone` and `Work Time`
 - Fill `Email`, `Latitude`, `Longitude` and click `Save Shop`

- [x] Add Google Api Key for the map to work
 - Log in admin and go to `Stenik/Shop`
 - Scroll to `API Key` and fill Google API Key
 - click `Save Config`
 - now go back on front and stores should be showing on Google Maps
