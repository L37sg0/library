## Fix hardcoded trigger users in a MySql dump
```bash
sed -i 's/DEFINER=[^*]*\*/\*/g' <magento2_mysql_backup_file.sql>
```

## Need to switch between two websites in a multisite magento installation
- Find codes for webites in db table `store_website`
- 2 approaches:
    1. Change the default website by modifying column `is_default` in the table
    ```sql
    # Switch off the website which is the current default
    update store_website set is_default=0 where code='base';
    # Switch on the website you wish to work on
    update store_website set is_default=1 where code='b2b';
    ```
    2. Replace the following code snippet in your project `index.php`:
    ```php
    $bootstrap = Bootstrap::create(BP, $_SERVER);
    ```

    with this:

    ```php
    $params = $_SERVER;
    $params[\Magento\Store\Model\StoreManager::PARAM_RUN_CODE] = 'b2b'; // Place here the code for the website you need to work locally.
    $params[\Magento\Store\Model\StoreManager::PARAM_RUN_TYPE] = 'website';
    $bootstrap = Bootstrap::create(BP, $params);
    ```
