## 🎓 Courses & Learning Paths (/courses)

The courses directory contains detailed markdown notes and guides structured into various technical modules:

- Linux & Infrastructure:

    - Getting Started WithLinux: Linux fundamentals, command-line usage, file systems, permissions, and security.

    - Building an Ubuntu Server: Planning, storage management, networking (Netplan, UFW), virtualization (KVM, Docker, LXC), and common web/database services.

- DevOps & CI/CD:

    - DevOps Foundations: CI/CD concepts, pipeline building, and automation.

- Security & Authentication:

    - Web Security (OAuth and OpenID Connect): Deep dive into OAuth 2.0, grant types, tokens (JWT), PKCE, and security best practices.

    - SSL Certificates for Web Developers: Understanding HTTPS, CAs, Let's Encrypt (Certbot), and server configurations.

- Web3 & Cloud:

    - Web3 Design & Security Essentials: Introduction to decentralized technologies and the metaverse.

    - GitHub: Practical GitHub Actions and professional workflows.

- E-Commerce:

    - Magento 2: Installation, data patches, security updates, and MySQL queries.
