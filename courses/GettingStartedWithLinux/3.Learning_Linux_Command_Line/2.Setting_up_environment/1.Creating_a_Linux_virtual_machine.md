## Using a Virtual Machine
- VirtualBox running Ubuntu Desktop:
  - VirtualBox runs on Windows, macOS, and Linux
  - With a virtual machine, mistakes we make won't affect our real computer
- Ubuntu Desktop provides a user-friendly Linux environment

- Download software
  - [VirtualBox](https://download.virtualbox.org/virtualbox/7.0.14/virtualbox-7.0_7.0.14-161095~Ubuntu~jammy_amd64.deb)
  - [Ubuntu Desktop](https://ubuntu.com/download/desktop/thank-you?version=22.04.4&architecture=amd64)
- Create Virtual machine with 4GB RAM, 50 GB hdd VDI
- Install Ubuntu Desktop on it
- Update the software on Ubuntu Desktop
- Setup GuestAdditions for the new VM
- Install needed software
  - `sudo apt install gcc make perl`
- Insert GuestAdditions cd image and restart
- Eject GuestAditions image and power off
- Go to VM settings and set Display Video Memory to 128MB
- Start the VM again and login
- Go to View/VirtualScreen1 set to 100%
- Then go to View and click FullScreen mode
- Then inside the VM right click mouse and choose Display Settings and change scale to 200% -Apply
- Download the exercise files inside the VM and move them inside the Documents folder
