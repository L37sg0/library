## Following allong using other tools
- On Windows 10 and higher, consider using Windows Subsystem for Linux
  - See [Learning Windows Subsystem for Linux](https://www.linkedin.com/learning/learning-windows-subsystem-for-linux-16134127) for details
- On macOS, using a virtual machine is recommended.
  - [VMware Workstation](https://www.vmware.com/products/workstation-pro.html) and [Parallels Desktop](https://www.parallels.com) are alternatives to VirtualBox
  - The version of `Bash` that macOS uses is outdated
  - macOS uses `Zsh` instead of `Bash`
- An already-configured Linux system is a good choice
- Following along using a remote system is possible but requires additional configuration.
- In any case, download the exercise files from GitHub.
