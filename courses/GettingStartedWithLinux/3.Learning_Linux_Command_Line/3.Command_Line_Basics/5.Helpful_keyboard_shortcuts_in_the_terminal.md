## Useful Keyboard Shortcuts
- Tab completion:
  - Automatically completes a file or folder name
  - Makes guesses based on the contents of the path

## Text navigation Shortcuts
|Key Combination|Result|
|---------------|------|
|Ctrl-A(^A)|Move to beginning of line|
|Crtrl-E(^E)|Move to end of line|
|Ctrl-Left arrow|Move left one word|
|Ctrl-Right arrow|Move right one word|
|Ctrl-U|Delete from cursor to line start|
|Ctrl-K|Delete from cursor to line end|
|Ctrl-Shift-C|Copy selected text to clipboard|
|Ctrl-Shift-V|Paste text from clipboard|
|Up arrow|Recall previous commands|
|Down arrow|Scroll previous commands|
|Ctrl-R|Search command history|
|Ctrl-C|Cancel command|

## What is a Line
- Long commands or long series of commands can wrap at the window boundary, but these are still considered one line.
- A line is any text we type at the command prompt before pressing `return`(Enter)

  ```bash
  bash$: ls -lah /
  bash$: ip a
  bash$: rsync -avh --progress /
  mnt/external/work /mnt/backups/work
  bash$:
  ```
**Shortcut keys help increase efficiency.**
