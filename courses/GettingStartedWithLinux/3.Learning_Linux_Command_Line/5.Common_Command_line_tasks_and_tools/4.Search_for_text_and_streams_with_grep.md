## Searching for text
- The `grep` command searches files for matching patterns
- Match patterns can be explicit or specific
- Match patterns can use regular expressions
  - `grep "the" poems.txt` - shows only those lines from a file which contain "the"
  - `-n` - shows the number of each line matching
  - `-i` - returns case insensitive matchings - "the" will match both "the" and "The and "ThE" and etc.
  - `-v` - returns only matches which ignore the search term
  - `-E` - returns regular expression matches `grep -E "[hjk]" poems.txt` will return only lines with the letters "h" , "j" or "k"
    - `grep -E "\w{6,}" poems.txt` - will return only lines with words more than 6 or equal characters
    - more info in [Learning Regular Expressions course](https://www.linkedin.com/learning/learning-regular-expressions-15586553/write-text-matching-patterns)
- **Using grep with regular expressions is a useful skill**
