## The UNIX Philosophy
- A tool should do **one** thing and should do it **well**
- Tools should use text interfaces (take in text and output text)
- Tools should be designed to be used together in different ways
- The standart GNU coreutils follow this pattern
- Tools should be **Dedicated**
- Use each tool for what it's good at, and combine tools when needed
- **Modularity and flexibility are the goal**
