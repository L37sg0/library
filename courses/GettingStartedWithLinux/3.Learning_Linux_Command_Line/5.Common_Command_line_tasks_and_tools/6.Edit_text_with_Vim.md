## Editing Text with Vim
- The `vi` tool was a popular editor
- The `vim` tool is an improved version with modern features
- It takse a while to become good at using `vi/Vim`
- Look more at [Learning vi](https://www.linkedin.com/learning/learning-vi)
  |Command|Effect|
  |-|-|
  |i|Insert at cursor location|
  |I|Insert at beginning of line|
  |o|Insert on following line|
  |Esc|Enter command mode|
  |Esc :w|Save file|
  |Esc :wq|Save and exit|
  |Esc :q!|Exit without saving|
