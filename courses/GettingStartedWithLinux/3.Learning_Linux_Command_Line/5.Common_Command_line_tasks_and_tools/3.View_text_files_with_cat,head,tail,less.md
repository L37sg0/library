## Tools for Text
- `cat`
  - **Concatenate** means to link together
  - Can be used to output text file contents to the screen or to another program
  - `cat -n` - adds a line number to each line of the file
- `head` - View lines from the beginning of a file
  - accepts the `-n` option
  - `head -n5 poems.txt` - shows the first 5 lines of the file
- `tail` - View lines from the end of a file
  - also accepts the `-n` option
  - `tail -n10 poem.txt` - shows the last 10 lines of the file
- `less`
  - Displays text one page or screenful at a time and provides navigation controls
