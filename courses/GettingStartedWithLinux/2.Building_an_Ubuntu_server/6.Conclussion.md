## Exposing a Server to the internet
- Port forwarding is usually configured in a home router's web GUI.
- In an organisational setting, you may need to edit firewall rules directly.
- Port forwarding provides two points of firewall control.
- Port forwarding allows granting access specifically to one port on the system.
- Port forwarding doesn't prevent security problems.
- Exposed services should be secured and their software kept updated.
- Some services have a small attack surface.
- Interactive services provide more opportunity for attack.
- Configure SSH to use keys and not accept passwords.
- Software like Fail2ban can help reduce unwanted traffic.
- When passwords are required for log-in, ensure that they're strong enough.
- Configure HTTPS as appropriate on external-facing web services.
- Consider only accessing the server from outside your network through VPN.
- Decide how open your server needs to be, based on what its role is.
- Never expose Samba to the internet without protection.
- Consider using a dynamic DNS service if your external IP is subject to change.
- If you have a static IP, you can set a name for the server using DNS manually.
