## Usage
- `sudo apt install docker.io` - install docker
- `sudo docker search <searchterm>` - search for an image
- `sudo docker pull <imagename>` - pulls an image locally
- `sudo docker run -it <imagename> <command>` - run an image and execute a command inside of it.
  - Conrainers runned this way will only exist till there is a service executing inside of them.
- `nano mydockerfile` - create a Dockerfile
  - ```bash
    FROM alpine:latest
    CMD cat /etc/*release
    ```
- `sudo docker build -t mycontainer - < mydockerfile` - create a container from a Dockerfile
