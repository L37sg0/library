## Cloud Services with Nextcloud
- Nextcloud provides on-premises data storage and sync options.
- Nextcloud is widely used by people and organisations.
- Nextcloud can be installed manually or by using the Snap package manager.
- [Nextcloud website](https://nextcloud.com/)
- Explore the [Nextcloud documentation](https://docs.nextcloud.com/server/latest/user_manual/en/) to learn more.
- Secure your installation with HTTPS and manage access carefully.

## Nextcloud setup
- Make sure port 80 is open in firewall
- `sudo snap install nextcloud` - install Nextcloud
- access the web interface and setup an admin account
- configure the server in the web interface
- install a client app on your mobile device and use it.
