## Containers
- Isolated space to run an operating system
- OS inside the container uses the host's kernel
- Can be given access to host resources, like network and storage
- LXC/LXD are available to manage containers on Ubuntu
- [documentation of LXC/LXD](https://linuxcontainers.org/)

## How it works
- initialize a container with `sudo lxd init` - and answer the questions
- add your user to the `lxd` workgroup `sudo usermod -aG lxd <username>`
- `lxc launc images:alpine/3.13` - launch a container specifying an image to be used
- [available images](https://images.linuxcontainers.org/)
- view enabled remotes with `lxc remote list`
- see running containers on the host `lxc list`
- execute commands on container `lxc exec <container-name> <command>`

## Transfering files between host and containers
- copy a file from host to container `lxc file push <filename> <container>/<path>`
- copy a file from container to host `lxc file pull <container>/<path>/<filename> <filename>`

## Controlling containers
|Command|Function|
|-------|--------|
|`lxc stop <containername>`|stops a container|
|`lxc start <containername>`|starts a container|
|`lxc delete <containername>`|delete a container|

- **Containers allow us to easily manage an isolated environments, without the overhead of running full virtual machines.**
