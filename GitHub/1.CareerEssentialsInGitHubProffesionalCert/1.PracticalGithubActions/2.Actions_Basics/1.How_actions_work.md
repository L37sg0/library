## How GitHub Actions work
- Actions make it easy to automate your workflow, by executing something each time you make a push to your repository or somebody make a pull request.
- You can create wour own actions, or use such created by the comunity, which can be found on GitHub marketplace.
- [GitHub Actions documentation](https://docs.github.com/en/actions)
