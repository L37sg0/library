## Create a repository
- Log in Github and create new repository in your personal account
- call it `podcast-test`
- download as a `zip` the [Exercise Files repository branch 01_02b](https://github.com/LinkedInLearning/github-practical-actions-4412872/tree/01_02b)
- extract what you've downloaded and upload to your new repository the following files:
  - dir `audio`
  - `feed.yaml`
  - dir `images`
  - `README-feed.md`
- rename `README-feed.md` to `README.md`

## Create GitHub pages
- in your repository go to `Settings/Pages`
- select `Deploy from a Branch`
- select branch `main` and dir `/root`
- click `Save`
- you should be able to visit your new pages website in short.
